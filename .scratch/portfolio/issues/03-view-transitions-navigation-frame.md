# 03: View Transitions & Navigation Frame (Home, Projects, Contact)

**What to build:**
Implement seamless page-to-page transitions using the native browser View Transitions API across all primary portfolio routes. Build out the core navigation frame, the executive Homepage, the Projects showcase grid, and the Contact page with copyable email interaction and social links.

**Blocked by:** 02: Dual Presentation Modes & Bottom-Right Peel Switcher

**Type:** Feature
**Status:** To Do

## Acceptance criteria

- [ ] Route navigation wrapped in native `View Transitions API` (`document.startViewTransition`) with fluid CSS cross-fade and scale transforms.
- [ ] Navigation header and footer with accessible route links.
- [ ] Homepage with executive bio, headline, and featured work spotlight.
- [ ] Projects page rendering curated projects with tags, external live links, and repository links.
- [ ] Contact page with curated social links and an interactive email pill with animated "Copied to clipboard!" feedback.
