# Triage Labels and Statuses

This file maps this repo's Linear workflow, Kanban states, and issue type labels to triage expectations.

## Kanban States

- **To Do**: Open tasks prioritized for implementation.
- **Doing**: Work currently in progress.
- **Done**: Completed work verified and merged.
- **Won't Do**: Rejected or closed out-of-scope issues (equivalent to `wontfix`).

## Issue Labels

We categorize all tickets into the following labels:

| Label | Meaning |
| ----- | ------- |
| **Bug** | A defect, regression, or unintended behavior in the codebase. |
| **Feature** | New functionality or user-facing capability. |
| **Improvement** | Refinement, optimization, or enhancement of existing behavior. |
| **Chore** | Maintenance, tooling, dependency updates, or internal cleanup tasks. |
| **Spike** | Investigative or research task requiring exploration, prototyping, or clarification before work can be estimated or built (equivalent to `needs-info` / `needs-triage`). |

When creating tickets or triaging, categorize issues using one of these labels and place them in the appropriate Kanban status column.
