# Issue Tracker: Linear

Issues for this repo are tracked in Linear.

- **Project URL**: [Portfolio Project](https://linear.app/shouryannikam/project/portfolio-8697af83f6a4/issues)
- **Integration**: Configured via the Linear MCP server (`mcp-remote https://mcp.linear.app/mcp`).

## Creating Tickets

When skills such as `to-tickets` create issues:
1. Create the issue in the **Portfolio** project (`portfolio-8697af83f6a4`).
2. Set initial state to **To Do** (or **Triage** / **Needs Info** if questions remain).
3. If creating via MCP tools is unavailable or pending authorization, format the issue in Markdown with clear title, description, acceptance criteria, and project link so the user can review or paste it into Linear directly.

## Workflow States

Linear Kanban columns map as follows:
- **To Do**: Open tasks prioritized for implementation.
- **Doing**: Work currently underway.
- **Done**: Completed work verified and merged.
- **Won't Do**: Rejected or closed out-of-scope issues.
